# Subtitle Finder — Android APK source

تطبيق أندرويد يبحث في SubDL عن ترجمتين عربية وإنجليزية للفيديوهات داخل مجلد تختاره، ثم يحفظ الملفات بجانب الفيديو.

## قبل البناء
1. أنشئ حسابًا في SubDL واحصل على API key مجاني من لوحة الحساب: https://subdl.com/api-doc/
2. نزّل Android Studio على كمبيوتر، وافتح هذا المجلد باستخدام **Open**.
3. وافق على تثبيت Android SDK Platform 35 وAndroid Gradle Plugin المطلوب إذا طلب Android Studio ذلك.
4. من إعدادات Android Studio اختر JDK 17 لـ Gradle (عادةً Embedded JDK)، وانتظر Gradle Sync، ثم اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. ستجد APK غالبًا في:
   `app/build/outputs/apk/debug/app-debug.apk`
6. انقل APK إلى هاتف Android وثبّته. قد تحتاج للسماح بالتثبيت من هذا المصدر.

## الاستخدام
1. افتح التطبيق والصق SubDL API key.
2. اضغط اختيار المجلد واختر مجلد الأفلام أو المسلسلات. امنح التطبيق صلاحية القراءة والكتابة.
3. اضغط Scan.
4. سيبحث التطبيق عن AR وEN ويحفظ الموجود منهما بجوار كل فيديو.

## أسماء الملفات
لأن التطبيق يحفظ لغتين، سيستخدم:
- `Movie.Name.ar.srt`
- `Movie.Name.en.srt`

أو الامتداد الأصلي الذي توفره الخدمة مثل `.ass`. هذا النمط يساعد مشغلات الفيديو على تمييز اللغة. لا يستبدل التطبيق أي ترجمة موجودة.

## ملاحظات مهمة
- يلزم الإنترنت أثناء البحث والتنزيل.
- يدعم حاليًا أسماء الحلقات بصيغتي `S01E02` و`1x02`.
- البحث يعتمد على اسم الملف وبيانات SubDL؛ قد لا يجد كل الإصدارات أو قد يختار ترجمة غير متزامنة. راجع الترجمة بعد التنزيل.
- التطبيق لا يرفع ملفات الفيديو؛ يرسل اسم الملف واسم العمل إلى SubDL للمطابقة.
- النسخة الحالية لا تفك ملفات ZIP الاحتياطية؛ تستخدم روابط الملفات المفردة التي يعيدها `unpack=1`.
- API key خاص بحسابك، لا تشاركه مع أحد. لا تضعه في نسخة عامة من التطبيق.
- بعض إصدارات Android/مزودي الخدمة قد لا يعيدون ملفات اللغة المطلوبة أو قد يحدّون التنزيلات.

## البنية
- Kotlin + Android native UI
- Storage Access Framework لاختيار المجلد دون طلب صلاحية شاملة للتخزين
- SubDL Search API v1
